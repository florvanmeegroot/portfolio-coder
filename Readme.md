# Portfolio de Florencia Van Meegroot

Este es mi portfolio personal creado con HTML, CSS y SCSS. Aquí muestro mis proyectos, habilidades y una breve presentación sobre mí y es mi proyecto final para el curso de Desarrollo Web de la Carrera de Full Stack de CoderHouse.

## ✨ Características

- Diseño responsive
- Utilización de SASS (variables, nesting, partials, extend o mixin)
- Animaciones CSS
- Código limpio y organizado
- Optimización SEO básica
